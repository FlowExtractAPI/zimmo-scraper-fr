# zimmo-scraper-fr
Collez simplement une URL de recherche zimmo.be directement depuis votre navigateur. Le scraper récupère la fiche complète de chaque annonce et stocke la réponse brute de l'API — vous obtenez ainsi chaque champ exposé par zimmo.be : prix, certificats EPC, statut d'inondation, informations d'urbanisme, revenu cadastral, contacts d'agence, images,
